# DermaPilot email drafts

These are local drafts for a future Afribase email setup. The app does not send these emails yet.

| Template | Suggested subject | When to send |
| --- | --- | --- |
| `verify-email.html` / `.txt` | Verify your DermaPilot email | Afribase signup confirmation |
| `welcome.html` / `.txt` | Welcome to DermaPilot | After email verification or first successful sign-in |

Before adding the verification template in Afribase, replace `{{VERIFY_URL}}` with the confirmation-link variable shown by Afribase's email-template editor. Replace `{{APP_URL}}` with the deployed app URL in both templates. These names are portable placeholders in these drafts; Afribase's exact variable syntax must be checked in its dashboard. The verification link must be generated by Afribase, not typed manually.

The welcome template is a separate message. Enabling signup confirmation alone does not necessarily send it; add a welcome-email trigger in Afribase or another email service when ready. Test both templates with a new account before relying on them.
